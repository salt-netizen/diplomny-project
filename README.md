# diplomny-project

Серверна частина (REST API) проєкту "клон Booking.com".

## Технології
- ASP.NET Core Web API (C#)
- JSON, контролери
- (база даних, коли визначитесь)

## Вимоги
- .NET SDK (вкажіть версію)
- Visual Studio 2022 або VS Code

## Запуск
1. Клонувати репозиторій
2. Створити `appsettings.Development.json` за зразком
3. Виконати `dotnet run`
4. Swagger: https://localhost:ПОРТ/swagger

## Структура
- Controllers — контролери API
- Models — моделі даних
- Services — бізнес-логіка
